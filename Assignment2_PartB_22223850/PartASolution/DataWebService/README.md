# COMP3008 Distributed Computing
## Assignment 2 - Part A: Data Web Service

A REST API for users, bank accounts, transactions and audit records

---

## 1. How to Run

The database is created and seeded automatically on first run

**Visual Studio**
1. Open the project solution in Visual Studio.
2. Set `DataWebService` as the startup project and press the green 'Run' arrow
3. Open Swagger: http://localhost:5234/swagger

## 2. .NET Version

Targets **.NET 8.0**.
